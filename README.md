# 🎯 FokusKu — Smart Study Focus

**Belajar lebih fokus, tugas lebih teratur!** 💚

FokusKu adalah mockup aplikasi belajar yang dirancang untuk membantu mahasiswa dan pelajar meningkatkan fokus, mengelola tugas, serta mengatur jadwal ujian dalam satu platform yang modern dan responsif.

## ✨ Fitur Utama
- 🏠 **Dashboard:** Ringkasan target fokus, tugas, dan statistik belajar.
- ⏱️ **Sesi Fokus:** Timer belajar dan simulasi deteksi distraksi.
- 📝 **Tugas & Ujian:** Mengelola tugas, tenggat waktu, dan prioritas.
- 📊 **Ringkasan:** Melihat statistik fokus dan riwayat belajar.

## 🛠️ Teknologi
HTML, Tailwind CSS, Vanilla JavaScript, Node.js, GitHub, dan Railway.

## 🚀 Tujuan Proyek
Membuat mockup MVP yang modern, responsif, dan interaktif sebagai langkah awal untuk mengembangkan aplikasi belajar yang membantu pengguna lebih produktif.

## ⚠️ Catatan
FokusKu masih berupa mockup front-end. Deteksi distraksi masih berupa simulasi, dan data belum tersimpan secara permanen.
